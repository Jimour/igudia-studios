# IGUDIA Studios

IGUDIA Studio is an interactive Progressive Web App (PWA) for learning Computer-Generated Imagery (CGI), exploring 3D concepts, creating interactive scenes, managing projects, and showcasing digital work.

## ✨ Features

- 🎨 Interactive 3D Studio powered by Three.js
- 🧍 Human character creation
- 🧊 3D primitives including cubes, spheres, cones and torus objects
- 🎮 Interactive camera controls
- 💡 3D lighting and environment
- 🔧 Object selection and property editing
- 📐 Position and rotation controls
- 🧩 Object duplication and deletion
- 📝 CGI learning notes
- 🕐 CGI history timeline
- 📚 Tutorials and challenges
- 🚀 CGI future technology section
- 🗺️ Beginner CGI learning roadmap
- 📁 Project creation, saving, opening, renaming and duplication
- 🖼️ Personal CGI gallery
- 📤 PNG scene export
- ⚙️ User settings
- 📱 Responsive mobile design
- 💻 Installable as a desktop/mobile PWA
- 🌐 Offline-ready architecture

## 🧠 About CGI Studio

CGI Studio was created as a personal learning and experimentation platform for exploring the world of Computer-Generated Imagery and 3D creation.

The project combines computer science, web technology and 3D graphics to create an interactive environment where users can learn concepts and experiment with digital scenes.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Three.js
- Vite
- Vite PWA
- Progressive Web App technologies
- Local Storage

## 🎓 Learning Areas

CGI Studio covers foundational CGI concepts including:

- Real-time graphics

## 🎮 3D Studio

The Interactive 3D Studio allows users to:

1. Create 3D objects
2. Add a human character
3. Move objects around the scene
4. Rotate objects
5. Select and edit objects
6. Duplicate objects
7. Delete objects
8. Toggle wireframe mode
9. Play character animation
10. Save projects
11. Export rendered scenes

## 📁 Project System

Projects can be stored locally in the browser.

Each project can contain:

- Project name
- 3D scene objects
- Object positions
- Object rotations
- Project thumbnail
- Creation date
- Last updated date

## 🖼️ Gallery

The Gallery provides a space for showcasing rendered CGI work created inside CGI Studio.

Exported scenes can be saved as gallery artwork and organized into categories.

## 📱 Progressive Web App

CGI Studio is designed as a Progressive Web App.

It can be installed on supported devices and provides an app-like experience with an architecture designed for offline use.
